# Atlassian MCP Light Autotests

Внешний black-box AQA-проект для проверки [Atlassian MCP Light](https://github.com/Solomentcev/atlassian-mcp-light).

Тесты взаимодействуют с собранным исполняемым JAR через MCP STDIO-интерфейс и проверяют JSON-RPC/MCP, интеграцию с Jira и Confluence, а также запуск отдельного процесса. Внутренние Java-классы основного приложения не являются объектом тестирования.

## Технологии

- Java 17
- Maven
- JUnit 5
- AssertJ
- Jackson
- Allure Report
- Jenkins

Для первой версии используется собственный минимальный MCP STDIO-клиент на Java/Jackson. MCP SDK и Mockito не включаются без отдельной технической необходимости.

## Основной подход

1. Собрать JAR основного проекта.
2. Запустить JAR как отдельный процесс через `ProcessBuilder`.
3. Обмениваться сообщениями через stdin/stdout; stderr читать отдельно.
4. Проверить MCP handshake, обнаружение инструментов и вызовы.
5. Выполнить интеграционные проверки на выделенных тестовых ресурсах Jira и Confluence.
6. Сформировать Allure-отчёт и сохранить диагностические артефакты.

## Важно

- Не использовать production-проекты, пространства и данные.
- Секреты хранить в локальных переменных окружения или Jenkins Credentials.
- Не направлять в stdout тестовые логи: stdout процесса сервера зарезервирован под MCP/JSON-RPC.
- Тесты должны быть независимы от реализации внутренних классов основного проекта.
